Guía y Ejemplos de Uso

Cómo funciona la búsqueda: Buscar Solicitudes

Podés buscar por apellido y/o nombre de una persona
  • Si ingresas José encontrarás las solicitudes de las personas con este apellido o nombre.
  • Si ingresas José Ignacio Salinas encontrarás las solicitudes de las personas cuyos apellido y/o nombre contengan alguna de las palabras ingresadas.

Podés buscar por número de legajo ingresando cifras de hasta 6 dígitos, o podés usar "L:" (sea mayúscula o minúscula) interpretará cualquier número que le siga como un Legajo.

  • Si ingresas 000001, encontrarás las solicitudes de la persona con este legajo.
  • Si ingresas 000001 000012, encontrarás las solicitudes de las personas cuyos legajos se encuentren dentro del rango ingresado.
  • Si ingresas 000001 000006 000012, encontrarás las solicitudes de las personas con cada uno de estos legajos.
  • Si ingresas l:000001 000006 000012, encontrarás las solicitudes de las personas con cada uno de estos legajos.

Podés buscar por correo electrónico ingresando el dominio completo (persona@organizacion.com).

Podés buscar por el Identificador Fiscal ingresando una cifra a partir de 7 dígitos.
